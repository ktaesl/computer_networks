**Инкапсуляция данных**
Кадр - внутренняя структура кадра \
Адресация - кадр включает MAC-адрес источника и назначения для доставки кадра из NIC в одной локальной сети.\
Обнаружение ошибок - кадр включает трейлер последовательности проверок кадров (FCS), используемый для обнаружения ошибок.\
\
Доступ к среде передачи данных\

\
Поля кадра Ethernet
Мин.кадр - 64 байта
Макс.бкадр - 1518 байт
\
**MAC-адрес**
МАС-адреса шестнадцатеричные значения\
48-разрядный адрес может быть выражен только шестнадцетеричной системой\

Индивидуальный МАС-адрес (unicast) - уник.адрес, используемый при отправке кадра от одного передающего устройства к одному устройству\
Широковещательный МАС-адрес FF-FF-FF..-FF \
Групповой МАС-адрес\
\
**Способы переадресации кадров на коммутаторах Cisco**
Коммутация с промежуточным хранением - коммутатор получает кадр целиком и вычисляет циклический избыточный кода.\
Коммутация со сквозной пересылкой - коммутатор пересылает данный кадр до его полного получения.
\
**Сквозная коммутация**
Коммутация с быстрой пересылкой - пакет пересылается сразу же после чтения адреса назначения, с минимальным уровнем задержки.\
Коммутация с исключением фрагментов - компромисс между большой задержкой с высокой целостностью (коммутация с промежуточным хранением) и малой задержкой с меньшей целостностью (коммутация с быстрой пересылкой).\
\
**Буферизация памяти на коммутаторах**
Метод буферизации памяти используется для хранения кадров до их пересылки или когда порт назначения занят из-за перегрузки.\
\
**Настройка дуплексного режима и скорости**
Полнодуплексный режим - одновременная отправка и получение данных в обе стороны.\
Полудуплексный режим - отправка данных только одной стороной.\
\
Автоопределение - доп.функция, которая позволяет двум устройствам автоматически обмениваться информацией о скорости и возможностях дуплексного режима.\
