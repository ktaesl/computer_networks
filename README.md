Виды связи
Simplex - односторонняя связь.
Half-duplex -двусторонняя связь, но в один момент времени может передавать только одно устройство.
Full-duplex - двусторонняя передача, оба устройства могут одновременно вести передачу.

Unicast - передача данных одному адресату.
Broadcast - широковещательная передача данных всем адресатам
Multicast - передача данных группе адресатов
